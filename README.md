# Xal's Warchest

A weapon appearance tracker - the counterpart to Xal's Armoire, weapons only.

Same idea as Xal's Armoire: shows what you're still missing and where it
comes from, without burying you in checkboxes. Armoire covers armor; Warchest
covers weapons.

## Commands

| Command | What it does |
|---|---|
| `/xwc options` | Open the settings window |
| `/xwc help` | List the commands |

## Installing

Install from CurseForge, or drop the `XalsWarchest` folder into
`World of Warcraft\_retail_\Interface\AddOns\`.
